\section{Mục gitignored và quy tắc Git hygiene (R8)}
\label{sec:gitignored}

Các mục sau \textbf{không được phép track} (kiểm tra bởi CI và \code{scan\_secrets.py}):

\begin{itemize}
\item \code{config/keys.json}, \code{config/*.env} — secret local (R1); chỉ dùng template.
\item \code{credentials.h} (mọi nơi, \code{**/credentials.h}) — file sinh bởi
  \code{gen\_credentials.py}, gitignored.
\item \code{sdkconfig*}, \code{build/}, \code{.pio/}, \code{managed\_components/} —
  artifact build ESP-IDF/PlatformIO.
\item \code{report/*.pdf}, \code{report/*.log} + \code{*.aux/*.toc/*.out/...} — artifact
  LaTeX (R8: binary qua GitHub Release/LFS).
\item Ngược lại, \code{dependencies.lock} (ESP-IDF component manager) \textbf{phải được
  track} để tái lập build.
\end{itemize}

\section{Liên hệ thư mục -- tầng kiến trúc}
\label{sec:dir-layers}

Ánh xạ thư mục tới 5 tầng ở Chương~\ref{ch:project-structure}:
Tầng 1 (shared contract) = \code{firmware/shared/}; Tầng 2 (sensor) =
\code{firmware/sensor-node/}; Tầng 3 (screen) = \code{firmware/waveshare-screen/};
Tầng 4 (cloud) = \code{cloud/coreiot/} + \code{tools/test\_mqtt\_coreiot.py};
Tầng 5 (enforcement) = \code{.opencode/} + \code{tools/guard/} +
\code{.github/workflows/ci.yml}.
